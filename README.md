# Maple English 🍁

给在加拿大生活的成年人用的英语练习网站，重点练听力和口语，目标是能和人交流、听懂 CBC 新闻。

- **单词**：5050 个（加拿大生活、CBC 新闻、短语动词、核心词），间隔复习
- **听写**：1004 句，分日常、新闻短句、新闻长句三级，逐词标错
- **口语**：100 个生活情景对话，跟读录音打分
- **CBC 计划**：从零到听懂 CBC 新闻的学习路线

纯前端，不需要服务器。学习进度按用户名保存在浏览器里，可在「设置」中导出 / 导入备份。

**使用建议**：iPad 用 Safari 打开（可一键录音跟读），电脑用 Chrome 或 Edge 打开。

**本地运行**：双击 `start.bat`，或在文件夹里运行 `python -m http.server 8765` 后打开 http://localhost:8765
